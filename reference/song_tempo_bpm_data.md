# Song tempo (BPM) data

Song tempo (BPM) data

## Usage

``` r
song_tempo_bpm_data
```

## Format

dataframe with one row for each song with a personally-measured tempo
reading.

- song:

  The name of the song

- tempo_bpm:

  Tempo, in beats per minute, measured personally by Alex Mitrani

## Provenance

Raw-hand-curated, from `inst/extdata/song_tempo_bpm_data.csv`. Read
as-is by
[`Repeatr_1`](https://alexmitrani.github.io/Repeatr/reference/Repeatr_1.md),
no transformation. Not exported to fugazibase - kept in `Repeatr` only,
for its own Shiny app.
