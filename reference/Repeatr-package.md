# Repeatr: Exploring the Fugazi Live Series

'Repeatr' is a package of data and functions for exploring the Fugazi
Live Series. The data is from
<https://www.dischord.com/fugazi_live_series>. There is online
documentation for this package here:
<https://alexmitrani.github.io/Repeatr/>.
