# 899 stacks of 10-12 shows covering the whole Fugazi repertoire (94 songs), one for each show in the Fugazi Live Series.

899 stacks of 10-12 shows covering the whole Fugazi repertoire (94
songs), one for each show in the Fugazi Live Series.

## Usage

``` r
gid_initial_gid_sound_quality
```

## Format

dataframe with one row for each combination of initial show and stacked
show.

- gid_initial:

  show id of the initial show, used to identify each stack of shows

- gid:

  show id of each show contained within each stack

- sound_quality:

  Sound quality rating: Excellent, Very Good, Good, or Poor.

## Source

https://www.dischord.com/fugazi_live_series

## Provenance

Derived, generated once (via
[`sweepstack`](https://alexmitrani.github.io/Repeatr/reference/sweepstack.md)/[`stacks`](https://alexmitrani.github.io/Repeatr/reference/stacks.md))
and not regenerated by any current `R/` pipeline stage or by
`data-raw/build_data.R` - do not assume it reflects the latest
`duration_data_da`. Actively consumed directly by
`inst/shiny/Fugazetteer/app.R` for the "stock" pages, so despite being
un-regenerated it is not orphaned; confirm via `R/`, `vignettes/`, and
`app.R` before ever tagging it (or anything else) `Frozen-legacy`.
